## Verified facts

- 53 public tool-proof pages: 52 tools exercised locally and Claude Code
  recorded as installed-only because it was not authenticated or invoked.
- Twelve specialist workflows for documents, spreadsheets, decks, PDFs,
  research, data, diagrams, publishing, building, debugging, review, and ship
  readiness.
- Thirty CLI-selectable career toolpacks: ten from a general high-pay snapshot,
  ten finance packs, and ten engineering packs.
- Salary context uses named U.S. Bureau of Labor Statistics tables. It is a
  transparent U.S. proxy, not a claimed worldwide ranking.
- Apple-silicon and Intel macOS setup paths are tested. The installer does not
  sign into agent accounts or copy credentials.

## One-line pitch

Wut CLI turns a new Mac into a persistent AI workbench with 53 verified tool
workflows, twelve specialists, and 30 career toolpacks.

## Short description

WutPack is an open-source macOS installer and workflow layer for Codex and
Claude Code. It makes Office, PDF, browser, data, diagram, publishing, and
engineering tools persist across sessions, then exposes them through twelve
specialists and 30 role-shaped CLI toolpacks with explicit human-review
boundaries.

## Boilerplate

WutPack is an independent, MIT-licensed macOS workbench maintained in
Sunnyvale, California. It installs and connects durable open-source tools for
documents, spreadsheets, presentations, PDFs, research, data, browsers,
diagrams, publishing, and software workflows. WutPack does not provide model
accounts, professional advice, or professional certification; host permissions,
authentication, sensitive-data controls, and accountable review remain with the
user and their organization.

Adapt each post to the community and follow its self-promotion rules. Do not
