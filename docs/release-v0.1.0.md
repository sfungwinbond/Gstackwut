# WutPack 0.1.0: your new Mac's AI office

[Open the beginner launch page](https://sfungwinbond.github.io/Gstackwut/) or install directly:

```bash
curl -fsSL https://raw.githubusercontent.com/sfungwinbond/Gstackwut/main/install.sh | bash
```

WutPack turns a fresh Mac into a persistent knowledge-work harness for Codex and
Claude Code. It installs durable document, spreadsheet, presentation, PDF,
research, data, diagram, publishing, browser, and agent tooling, then routes work
through twelve focused specialists.

## What is in the first public release

- One guided installer for Apple silicon and Intel Macs.
- Codex and Claude Code installed by default, without touching account sign-in
  or credentials.
- Twelve specialist workflows shared by both agent hosts.
- Persistent Office, PDF, browser, diagram, data-science, publishing, and
  agent-tool environments.
- Editable PPTX, XLSX-compatible, CSV, SVG, PDF, and documentation workflows.
- Fictional consulting examples with no client or proprietary data.
- Clean-host CI proof on both Mac architectures, including generated artifact
  validation and a second idempotent repair run.

## Verified before publication

The public install passed the full clean-runner matrix on Apple silicon and

## The honest boundary

WutPack is an AI-first workbench, not a pixel-for-pixel Microsoft Office clone.
It uses standard editable formats and installs LibreOffice, but specialized
macros, tracked-change workflows, and proprietary extensions may still need the
original application. AI providers and optional services retain their own terms
and pricing.
