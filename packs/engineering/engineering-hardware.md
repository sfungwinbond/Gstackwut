# Computer hardware engineering toolpack

Use this pack for requirements traceability, interface documentation, test-data
analysis, design reviews, verification planning, and technical communication.

## Workflow

1. Fix product revision, interfaces, requirements baseline, units, and owners.
2. Build bidirectional requirement-to-test traceability with unresolved gaps.
3. Analyze bench results with calibration, uncertainty, and outliers visible.
4. Diagram architecture, timing, dependencies, and failure containment.
5. Deliver review evidence with decisions, actions, and approval gates.

## Deliverables

- Requirements and verification matrix
- Reproducible test analysis
- Editable architecture and design-review package

## Safety boundary

This toolpack does not certify hardware, authorize release, or replace electrical,
thermal, EMC, reliability, security, and manufacturing engineering review.

## Starter prompt

Use the computer hardware engineering toolpack. State revision, interfaces,
requirements baseline, units, tolerances, and source evidence. Preserve raw test
data, quantify uncertainty, and trace each claim to a requirement and test. Map
dependencies and failure containment. This does not certify hardware or
authorize release. Produce editable engineering evidence for independent design,
safety, security, manufacturing, and accountable-owner review.
