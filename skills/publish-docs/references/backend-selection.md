# Publishing backend selection

- Quarto: executable reports, notebooks, citations, sites, books, and multi-format output.
- Pandoc: direct document conversion and custom filters without a site framework.
- MkDocs Material: approachable Markdown documentation sites with strong navigation.
- Sphinx: Python API reference, cross-references, and large technical manuals.
- pdoc or PyDoctor: fast source-code-to-HTML API documentation.
- TypeDoc or JSDoc: TypeScript or JavaScript API documentation.
- Doxygen: mixed-language source trees and generated call or dependency views.

Choose one primary source format. Avoid editing generated HTML, PDF, or DOCX by hand.
