# Diagram tool selection

- Mermaid: documentation-native flows, sequences, states, ER diagrams, and GitHub rendering.
- Graphviz: dependency graphs, dense directed graphs, and automatic layout.
- PlantUML: detailed UML sequence, component, deployment, and class diagrams.
- Schemdraw: circuits and electronics symbols generated from Python.
- draw.io: hand-tuned general diagrams that need GUI editing.
- PptxGenJS: diagrams whose final editing surface must be PowerPoint.

Prefer SVG for documentation. Add PNG only for consumers that cannot render SVG.
